# Frontend

길담의 홈, 여행 조건 입력, 추천 결과, 코스 상세와 각 상태 화면을 담당합니다.

## 기술 스택

- React
- TypeScript
- Vite
- React Router
- Vitest
- React Testing Library
- CSS Modules

## 명령어

```sh
npm run dev
npm run lint
npm run typecheck
npm run test:run
npm run build
```

화면 데이터는 `services`를 통해 받고, mock 데이터는 UI 컴포넌트에서 직접
가져오지 않습니다.
